# /save-as-synthesis — 답변을 위키에 보존

방금 사용자의 질문에 대해 한 답변이 충분히 가치 있다고 판단되면, 이를 `wiki/syntheses/`에 페이지로 저장한다.

## 절차

1. 현재 대화의 마지막 질문 + 답변을 식별.
2. `wiki-page` 스킬의 synthesis 템플릿을 사용:
   ```yaml
   ---
   title: <제목>
   type: synthesis
   created: <today>
   updated: <today>
   sources: [...]   # 답변에 인용된 모든 source 페이지
   question: "<원래 질문>"
   tags: [...]
   status: draft
   ---
   ```
3. 본문에 질문과 답변을 정돈된 형식으로 옮김 (대화 어조는 빼고 위키 어조로).
4. 인용된 모든 source/페이지에 wikilink.
5. `wiki/meta/index.md`에 추가.
6. `wiki/meta/log.md`에 `## [date] query | <q>` 기록.

## 페이지 이름

사용자가 `$ARGUMENTS`로 제공하면 그것을 사용. 없으면 질문에서 자동 생성한 후 사용자 승인 받기:
```
저장할 파일명: wiki/syntheses/<auto-generated>.md
이름을 다르게 지정하실래요? 아니면 진행?
```

## 주의

- 모든 synthesis가 저장될 가치가 있는 건 아니다. **새로운 종합/연결**이 있을 때만 의미 있다.
- 단순한 사실 조회 답변은 저장 가치 낮음 — 사용자에게 그렇게 안내.
