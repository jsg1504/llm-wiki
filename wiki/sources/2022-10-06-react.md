# ReAct: Synergizing Reasoning and Acting in Language Models

> 행동 공간에 **언어**를 더한다. 환경을 바꾸지 않고 context만 갱신하는 "thought"를 행동과 번갈아 내게 하면 thought → action → observation 루프가 된다. 추론은 행동 계획을 세우고 고치며, 행동은 추론에 외부 사실을 공급한다. CoT의 hallucination은 사라지지만 대가로 reasoning error가 늘었다. 이 루프가 지금 에이전트의 기본 단위다.

## Key Claims

1. **정식화.** 에이전트는 시점 t에 관측 o_t를 받고 정책 π(a_t | c_t)로 행동한다. c_t는 지금까지의 관측·행동 전부다. ReAct는 행동 공간을 Â = A ∪ L로 넓힌다. L은 언어 공간이다. L의 행동(thought)은 **환경에 영향을 주지 않아 관측이 돌아오지 않는다.** 대신 현재 context를 추론해 c_{t+1}에 유용한 정보를 더한다.
2. **thought가 하는 일.** 목표 분해와 계획, 관측에서 핵심 추출, 진행 추적과 계획 전환, 예외 처리, 상식 주입, 검색어 재구성, 최종 답 종합.
3. **두 가지 밀도.** 지식 과제(HotpotQA, FEVER)는 thought-action-observation을 매 단계 번갈아 낸다(dense). 행동이 많은 의사결정 과제(ALFWorld, WebShop)는 **thought를 언제 낼지 모델이 정한다**(sparse).
4. **지식 과제 결과 (PaLM-540B).** 도구는 의도적으로 약한 Wikipedia API 세 개다. `search[entity]`, `lookup[string]`, `finish[answer]`.

   | 방법 | HotpotQA (EM) | FEVER (Acc) |
   |---|---|---|
   | Standard | 28.7 | 57.1 |
   | CoT | 29.4 | 56.3 |
   | CoT-SC (21 샘플) | 33.4 | 60.4 |
   | Act-only | 25.7 | 58.9 |
   | ReAct | 27.4 | 60.9 |
   | CoT-SC → ReAct | 34.2 | **64.6** |
   | ReAct → CoT-SC | **35.1** | 62.0 |
   | Supervised SoTA | 67.5 | 89.5 |

   ReAct는 Act-only를 두 과제 모두 이겼다. CoT에는 FEVER에서 이기고 **HotpotQA에서 졌다.** 최선은 둘을 섞는 것이다. ReAct가 정해진 단계(7/5) 안에 답을 못 내면 CoT-SC로, CoT-SC 다수결이 n/2 미만이면 ReAct로 넘긴다. 섞은 방법은 CoT-SC 21샘플의 성능에 3~5샘플로 닿았다.
5. **실패 유형 (HotpotQA, 사람이 200개 궤적 라벨링).**

   | 유형 | ReAct | CoT |
   |---|---|---|
   | 성공 중 hallucination(false positive) | 6% | 14% |
   | 실패 중 reasoning error | **47%** | 16% |
   | 실패 중 search result error | 23% | – |
   | 실패 중 hallucination | **0%** | **56%** |
   | 실패 중 label ambiguity | 29% | 28% |

   CoT의 주 실패는 hallucination이고, ReAct의 주 실패는 reasoning error다. ReAct 특유의 패턴은 **이전 thought와 action을 반복 생성하며 루프를 못 빠져나오는 것**이다. 저자들은 greedy decoding 탓일 수 있다고 추측한다. 쓸모없는 검색 결과(23%)가 들어오면 추론이 탈선하고 회복하기 어렵다.
6. **의사결정 과제 결과.** ALFWorld(134개 unseen 게임) 성공률은 ReAct 최고 71%, 평균 57%였다. Act-only 최고 45%, BUTLER(전문가 궤적 10⁵개로 imitation learning) 37%였다. **ReAct의 최악 시도(48%)가 두 방법의 최고 시도보다 높았다.** WebShop 성공률은 ReAct 40.0%, IL 29.1%, IL+RL 28.7%, 사람 전문가 59.6%였다. 프롬프트 예시는 1~2개다.
7. **추론의 내용이 중요하다.** 환경 피드백만 받아 적는 Inner Monologue식 thought(ReAct-IM)는 ALFWorld 53%로 ReAct 71%보다 낮았다. 하위 목표가 끝났는지, 다음 하위 목표가 무엇인지 판단하지 못했다. 저자들은 이것을 *"internal reasoning vs. simple reactions to external feedback"* 의 차이로 본다.
8. **규모와 학습.** PaLM-8B/62B에서 prompting으로 쓴 ReAct는 네 방법 중 최하였다. ReAct가 만든 정답 궤적 3,000개로 fine-tuning하자 최상이 됐다. fine-tuned 8B ReAct가 62B prompting 전부를 이겼다. Standard·CoT를 fine-tuning하면 사실을 외우게 하고, ReAct·Act를 fine-tuning하면 정보를 찾아가는 법을 가르친다고 해석한다.
9. **사람이 개입할 수 있다.** thought를 사람이 고치면 에이전트 행동이 바뀐다(Figure 5). 저자들은 해석 가능성·진단 가능성·통제 가능성을 장점으로 든다.
10. **모델 간 일반화.** GPT-3(text-davinci-002)로 같은 프롬프트를 쓰자 HotpotQA 30.8, ALFWorld 78.4로 PaLM-540B보다 높았다(부록 A.1).
11. **한계와 윤리.** 행동 공간이 크고 복잡한 과제는 시연이 많이 필요해 in-context 길이를 넘는다. 외부 환경과 연결된 LLM은 부적절한 정보를 찾거나 해로운 행동을 할 수 있다. 실험은 사적 정보가 없는 사이트로 제한했고 위험한 행동(실제 구매, Wikipedia 편집)을 행동 공간에서 뺐다.

## Notable Quotes / Passages

> *"The idea of ReAct is simple: we augment the agent's action space to Â = A ∪ L, where L is the space of language."*

> *"… which allows the model to perform dynamic reasoning to create, maintain, and adjust high-level plans for acting (reason to act), while also interact with the external environments … to incorporate additional information into reasoning (act to reason)."*

> *"… such a structural constraint also reduces its flexibility in formulating reasoning steps, leading to more reasoning error rate than CoT."*

## My Notes

- **구조는 남고 수치는 낡는다.** PaLM-540B few-shot 수치는 지금 모델로는 의미가 없다. 남는 것은 세 가지다. 행동 공간에 언어를 넣는다는 정식화, CoT와 ReAct가 실패를 **교환**한다는 관찰, 반복 루프라는 실패 모드다.
- 2024년 [[2024-12-19-building-effective-agents]]의 agent 정의("LLMs using tools based on environmental feedback in a loop")는 이 논문의 루프를 제품 언어로 다시 쓴 것이다. 그 글은 ReAct를 인용하지 않는다. *(계보는 이 위키의 해석이다.)*
