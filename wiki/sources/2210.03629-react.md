# ReAct: Synergizing Reasoning and Acting in Language Models

> 단일 LLM의 출력 스트림에 **자유 형식 thought**와 **환경 action**을 in-context few-shot으로 인터리브하는 prompting paradigm. action space를 `̂A = A ∪ L`(L = language space)로 확장. CoT의 hallucination을 외부 grounding으로 잡고, RL/IL trained baseline을 1~6 shot prompting만으로 큰 차이로 압도. 후속 멀티에이전트 framework들의 계보적 선조이자 standing baseline.

- **저자**: Shunyu Yao (Princeton CS, 1저자, Google Brain 인턴 중 작업), Jeffrey Zhao / Dian Yu / Nan Du / Izhak Shafran / Yuan Cao (Google Research, Brain), Karthik Narasimhan (Princeton).

- **공개**: react-lm.github.io, anonymous.4open.science/r/ReAct-2268/ (코드 + prompts).
- **base model**: PaLM-540B 주실험. Appendix에 GPT-3 결과(PaLM-540B보다 우수). PaLM-8B/62B finetuning 실험.
- **배경**: 2022년 CoT(Chain-of-Thought) 흐름과 별도로 LLM-as-policy(WebGPT, SayCan, Inner Monologue) 흐름이 있던 시기. ReAct는 이 둘을 합치려는 첫 명시적 시도.

## Key Claims

1. **Action space augmentation: `̂A = A ∪ L`** — agent가 매 step `t`에서 환경 action `a_t ∈ A`를 내거나 thought `̂a_t ∈ L`(자연어)를 낼 수 있다. thought는 환경에 영향 없이 context만 갱신: `c_{t+1} = (c_t, ̂a_t)`. thought의 용도는 ad-hoc — task decomposition · commonsense 주입 · plan 추적 · exception 처리 · 검색 reformulation 등 다양. **언제 thought를 낼지 자체가 LLM의 결정** (구조 강제 없음). few-shot in-context examples로 prompting (no training).

2. **Hallucination 제압 ↔ flexibility 손실 trade-off** — HotpotQA 200 trajectory(ReAct/CoT 각 100, 정답·오답 50씩) 수동 분석 (Table 2):

   | | ReAct | CoT |
   |---|---|---|
   | Success: True positive | 94% | 86% |
   | Success: False positive (hallucination 포함) | 6% | 14% |
   | Failure: Reasoning error | 47% | 16% |
   | Failure: Search result error | 23% | — |
   | Failure: **Hallucination** | **0%** | **56%** |
   | Failure: Label ambiguity | 29% | 28% |

   ReAct의 외부 grounding이 fact fabrication을 거의 제거하나, 구조적 제약 때문에 **이전 thought/action을 반복 생성하며 루프를 못 빠져나가는** 'reasoning error'가 새 주된 실패 모드. greedy decoding 부작용으로 추정 (footnote 4).

3. **ReAct + CoT-SC 결합이 단독보다 우월 (HotpotQA)** — PaLM-540B 결과 (Table 1):

   | Method | HotpotQA EM | Fever Acc |
   |---|---|---|
   | Standard | 28.7 | 57.1 |
   | CoT | 29.4 | 56.3 |
   | CoT-SC (21 sample) | 33.4 | 60.4 |
   | Act | 25.7 | 58.9 |
   | ReAct | 27.4 | **60.9** |
   | CoT-SC → ReAct | 34.2 | **64.6** |
   | **ReAct → CoT-SC** | **35.1** | 62.0 |
   | Supervised SoTA | 67.5 | 89.5 |

   결합 heuristic: A) ReAct이 N step(7 for HotpotQA, 5 for Fever)에 답 못 찾으면 CoT-SC fallback. B) CoT-SC majority answer가 n/2 미만이면 (자신감 부족) ReAct fallback. **HotpotQA에선 CoT 단독 > ReAct 단독**이지만 결합 시 best. **Fever에선 ReAct 단독 > CoT 단독**.

4. **Prompting만으로 RL/IL trained baseline 압도 (decision-making)** —
   - **ALFWorld** (text-based household game, Shridhar et al. 2020b, 134 unseen tasks, 6 task types): ReAct best 71% SR · avg 57% / Act best 45% · avg 45% / BUTLER (10⁵ expert traj IL 학습) 37%. ReAct **+34% absolute over RL/IL baseline**, 1~3 in-context examples로. ablation: ReAct-IM(Inner Monologue 스타일 dense external feedback) 53%로 ReAct 단독에 못 미침 → "thought의 유연성"이 핵심.
   - **WebShop** (Yao et al. 2022, 1.18M product 실 환경, 500 test instruction): ReAct 40.0% SR(Score 66.6) vs Act 30.1%(62.3) vs IL 29.1%(59.9) vs IL+RL 28.7%(62.4). ReAct **+10% absolute over IL+RL** with one-shot prompt. 단, human expert 59.6에는 한참 못 미침.

5. **Finetuning에서도 ReAct가 가장 잘 scale** — Figure 3: HotpotQA에서 PaLM-8B/62B 4가지 prompting/finetuning 비교. Prompting only로는 작은 모델이 ReAct format 학습 어려워 가장 약함. 그러나 **3,000 trajectory로 finetuning 시 ReAct가 4가지 중 best**: PaLM-8B finetuned ReAct > 모든 PaLM-62B prompting, PaLM-62B finetuned ReAct > 모든 PaLM-540B prompting. Standard/CoT finetuning은 hallucinated facts 암기 학습 위험이 있고, ReAct/Act는 'Wikipedia 접근법'을 학습 — 후자가 더 generalizable.

## Notable Quotes

> "We augment the agent's action space to `̂A = A ∪ L`, where `L` is the space of language. An action `̂a_t ∈ L` in the language space, which we will refer to as a thought or a reasoning trace, does not affect the external environment, thus leading to no observation feedback." (§2)

> "Hallucination is a serious problem for CoT, resulting in much higher false positive rate than ReAct (14% vs. 6%) in success mode, and make up its major failure mode (56%)." (§3.3)

> "While interleaving reasoning, action and observation steps improves ReAct's groundedness and trustworthiness, such a structural constraint also reduces its flexibility in formulating reasoning steps, leading to more reasoning error rate than CoT." (§3.3)

> "However, IM's 'inner monologue' is limited to observations of the environment state and what needs to be completed by the agent for the goal to be satisfied. In contrast, the reasoning traces in ReAct for decision making is flexible and sparse, allowing diverse reasoning types to be induced for different tasks." (§4)

> "Scaling up ReAct with multi-task training and combining it with complementary paradigms like reinforcement learning could result in stronger agents that further unlock the potential of LLMs for more applications." (§6, conclusion)

## My Notes

- ReAct의 가장 큰 idea는 단순함이다: **"action space에 language를 그냥 더해라"**. thought는 그저 환경에 영향 없는 token sequence이고, 그게 다음 action을 위한 context로 들어간다. 모델은 언제 thought를 낼지 자체를 학습. few-shot prompt가 그 패턴을 보여주면 LLM이 따라 한다 — 별도 모듈/loss 필요 없음. 이 단순함이 ReAct가 후속 작업의 building block으로 채택된 이유.
- 그러나 단순함의 대가는 **prompt 의존성**: 1-6 example로는 복잡한 action space를 충분히 cover 못 하고, finetuning이 답이라고 논문이 직접 인정 (§6 conclusion).
- HotpotQA에서 CoT가 ReAct를 단독으로 이긴다는 점은 흥미로움. 정답이 LLM의 internal knowledge에 이미 있을 땐 외부 검색이 오히려 noise가 된다. 그래서 'CoT-SC가 자신 없을 때만 ReAct로 fallback'이 가장 강한 결합. → 외부 도구를 쓸지 결정하는 게 진짜 hard problem.
- ReAct의 reasoning error 47% 중 'thought-action 반복 루프' 패턴은 본 논문이 footnote에서 'greedy decoding 한계' 추정으로만 언급. 후속 멀티에이전트 frameworks가 evaluator/critic을 두는 모티베이션 중 하나로 읽을 수 있음 — single agent의 self-loop 탈출 실패를 다른 agent가 잡아준다는 구도.
- AgentVerse 자체 10-task tool-use 벤치에서 ReAct 3/10라는 결과는 [[agentverse]] 측 selection bias 가능성을 배제 못함. ReAct 논문 자체는 multi-tool 실험을 명시적으론 안 함 (HotpotQA의 Wikipedia API는 search/lookup/finish 3 action으로 단순). AgentVerse가 디자인한 'Bing Search + browser + code interpreter + task API' 환경은 ReAct이 원래 설정한 simple action space보다 훨씬 풍부 — 단일 ReAct의 약세는 paradigm 한계라기보다 prompt budget · task complexity 한계일 수 있다.
- ICLR 2023이라는 시점이 의미 있음. 같은 시점에 CoT(NeurIPS 2022)·Self-Consistency·STaR·Selection-Inference 등 reasoning prompting 흐름이, 별도로 WebGPT·SayCan·Inner Monologue 등 LLM-as-policy 흐름이 각각 진행 중이었다. ReAct이 둘을 합치는 명시적 첫 시도라는 self-positioning은 historically 정확.
- 위키 측 정리: ReAct는 framework가 아니라 **paradigm/pattern**. github.com/OpenBMB/ChatDev처럼 설치하는 'system'이 아니라 prompt template + action loop. 그럼에도 'ReAct'라는 이름으로 후속 논문에서 아티팩트처럼 인용된다 → entity로 다루는 것이 자연스러움.
